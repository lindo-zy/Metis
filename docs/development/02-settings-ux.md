# 02 · 设置界面与管理体验规格

本章是待实现规格。目标宿主为系统“设置”中的 `MetisPrefs.bundle`，使用 UIKit / Preferences 原生导航和列表。v1 不增加独立 App，不为设置页引入 WebView 或复杂首页框架。

```text
│        PixPin · 模式、编辑、输出        │
│ [图标] 键盘与操作               已启用 >│
│        TypeX · 工具栏、面板、输入       │
│ [图标] 剪贴板                   已关闭 >│
│        KayokoX · 历史、收藏、悬浮预览    │

│ 应用规则                  3 个例外   >│

├ 管理与支持 ───────────────────────────┤
│ 导入、备份与恢复                     >│

│ 关于                                >│
└──────────────────────────────────────┘
```

首页只有总开关；模块是否启用在各模块首页修改，避免整行导航和小开关触摸区冲突。状态文字来自保存配置，运行状态需另有真实回执，不把“已保存”写成“所有 App 已生效”。无 runtime 回执时显示“等待运行状态”，不报假故障或假成功。

首页不堆放编辑器颜色、长截图采样间隔等参数，不展示密钥、剪贴板内容、设备内部路径。

## 3. 每个模块的标准页面

模块首页顺序固定：启用与状态 → 常用设置 → 功能分组 → 高级/维护。末尾显示“恢复本模块设置”，与“删除业务数据”分开。

关闭模块后仍可进入并编辑配置，测试入口置灰，说明“启用模块后可测试”。模块未编入当前版本时显示“此版本尚未提供”，不能用关闭状态掩盖未实现。

### 3.1 截图与标注

| 页面 | 必须包含 | 交互与默认规则 |
| --- | --- | --- |
| 模块首页 | 启用、运行状态、六种截图测试入口 | 测试模式列表只执行选择项；测试动作和“复制入口链接”分开 |
| 截图模式与选区 | 区域/冻结/即时说明、记住选区、吸附距离 | 数值显示 pt；范围继承有效校验；不能把实时模式全部替换为冻结模式 |
| 长截图 | 自动/智能/采样、滚动、节奏、片数/画布/质量 | 常用模式在前，细粒度参数折叠到高级；说明长图内存降级 |
| 编辑器与按钮 | 全屏标记/区域工具栏、动作和工具排序、隐藏、自定义名称与图标、自定义 URL | 共用按钮编辑器；预览使用真实布局算法；每行最多 8 个，超出换行 |
| 输出与结果 | 默认结果动作、保存同时复制、气泡、悬浮图阴影、反馈 | “默认结果动作”枚举从源码目录生成，不凭标题猜值 |
| 高级与外部兼容 | 外部 URL 说明、旧协议兼容、可用第三方能力 | 可选外部依赖缺失给出原因，内部功能不依赖 ShellX |

截图模式“测试”会产生真实截图，应在按钮上标出操作，不要单击一个链接说明行就同时复制和截图。复制入口时只复制文本，并由设置动作登记本次写入，默认不进入剪贴板历史。

### 3.2 键盘与操作

| 页面 | 必须包含 | 交互与默认规则 |
| --- | --- | --- |
| 模块首页 | 开关、测试输入框、当前工具栏摘要 | 输入框用于本地键盘展示，不充当设置搜索框 |
| 顶部/底部工具栏 | 独立排序、开关、按钮编辑、样式、颜色、行数与尺寸 | 顶部保留最多 16 个启用、每行 1–8 且最多两行；底部最多 8 个，超限保留为停用项 |
| 键盘面板 | 新建/命名/类型、内容、系统控件、排序、布局 | 键盘面板与桌面手势面板能力不同，选择器按执行上下文过滤 |
| 键盘收起把手 | 原有把手参数、拖动/贴边/恢复、关联面板 | 保留原入口和手势含义；预览不承诺设备触摸已验证 |
| 悬浮应用与停靠栏 | 打开方式、大小位置、面板应用、底部六槽 | 六槽保持，不重新分页成旧八槽；普通/悬浮启动含义清晰 |
| AI 问答与脚本 | 引擎、人设、API、模型、流式；脚本管理和测试 | 凭据为安全输入；测试请求可联网必须显式点击，正文不会自动上传 |
| 输入辅助 | 悬浮粘贴与按应用规则、短信验证码复制 | 验证码默认关闭；悬浮粘贴应用授权默认无应用 |
| 浏览器重定向 | 独立开关、原配置与限制说明 | 默认关闭，不和 URL Scheme 动作合并成一个开关 |

按钮编辑页以“显示内容 → 基本动作 → 单击/长按/四向滑动 → 子动作 → 外观”组织。区分“长按选择子动作”和“按顺序执行全部”，必须沿原实际行为映射，不因界面术语改变执行含义。

### 3.3 剪贴板

| 页面 | 必须包含 | 交互与默认规则 |
| --- | --- | --- |
| 采集与历史 | 文本/图片、最大条数、远程剪贴板、保留策略 | 新装启用采集需明确操作；不将旧配置缺失解释为同意记录 |
| 收藏、标签与筛选 | 标签管理、颜色、初始视图、分类/应用/标签组合筛选 | 设置页只配置；浏览和搜索历史在运行面板完成 |
| 面板与画廊 | 高度、缩放、颜色、预览行数、详情、历史/收藏画廊 | 历史与收藏画廊分别控制 |
| 悬浮预览 | 开关、大小、持续时间、颜色、位置、倒计时环、双击 | 保留独立浮窗，透明区域触摸穿透 |
| 粘贴与焦点 | 自动粘贴、经典/模拟/自动、外点收起、提升策略 | 密码输入/焦点过期必须失败退出，不贴到新的输入框 |
| 文本与图片动作 | 文本菜单、图片菜单、图片双击动作 | 选择动作中心的动作引用，区分 text/image 输入能力 |
| 隐私与应用过滤 | 遮罩、应用排除、敏感写入记录策略 | 隐私遮罩只描述显示效果，不能写成数据库已加密 |
| 数据维护 | 缓存清理、检查、来源导入、历史/收藏清空 | 清空历史、清空收藏、清缓存、重置设置分别独立 |

原 `OverlayWindowLevel` 原始数值放高级兼容项并标“迁移值”；正式常用界面提供受支持的层级策略。不能保留“永远最高层”作为跨模块默认。

## 4. 动作中心

统一管理“动作是什么”，工具栏/手势/剪贴板只管理“哪里引用动作”。

```text
动作中心                         [+]
[搜索名称、类型、分组]
[全部] [文本] [应用/链接] [脚本] [系统]
常用                        5 项  ▾
  区域截图        截图 · 内置      >
  打开微信        应用 · 自定义    >
未分组                      2 项  ▾
  翻译选中文字    JavaScript      >
```

- 内置动作目录只读；自定义动作可新建、复制、重命名、归组、排序、批量处理。
- 同一动作只有一个稳定 UUID；改名不改变引用。模块不支持时灰显并展示原因，保留已绑定引用。
- 编辑页展示“被 3 处引用”，可进入工具栏/手势/剪贴板位置。删除被引用动作时，先展示影响；可取消，或确认删除并把引用改为明确的 missing 状态，不能悄悄换成默认动作。
- 类型：文本、URL、URL Scheme、App、系统快捷项、JavaScript、系统动作；内置截图与剪贴板作为能力动作，不复用外部安装探测。
- 图标选择统一支持 SF Symbol 和 Bundle ID；源码资源及许可各自保留，不把任何字符串默认当应用 ID。
- 无法迁移的旧参数展示“需检查”的原始摘要，不丢弃原数据，不执行任意 selector 字符串。

## 5. 手势与入口

按来源分区：键盘顶部/底部、键盘面板、状态栏左中右、Dock、剪贴板呼出、外部入口。支持模块筛选与“只看已绑定”。

每行显示：触发位置 + 手势 → 动作 + 生效上下文。冲突检测使用 `surface + direction/tapCount + context`，不以同一个汉字名称判冲突。

已有绑定被抢占时，编辑器展示双方名称，用户选择“保留原绑定 / 替换 / 限定应用或场景”；保存必须显式解决冲突。未解决的旧数据不激活新增竞争手势，保留确定的旧归属并显示待处理。

保留 TypeX 长滑/短滑语义、Kayoko 激活方式位掩码；不能把不同 gesture threshold 简单归为相同手势。一个触发最多执行一次，失败、锁屏、取消、手势距离不足不得触发。真正冲突的多个 recognizer 应合并为一个拥有者或建立 failure dependency，不能只靠同时回调后的防抖。

## 6. 应用规则与模块协作

应用规则是一张矩阵：应用 → 键盘工具栏 / 悬浮粘贴 / 剪贴板记录 / 其他受支持能力。每项明确显示“跟随默认 / 开启 / 关闭”，而不是一个覆盖所有功能的黑名单。

优先级：安全限制 → 总开关 → 模块开关 → 功能开关 → 应用显式规则 → 模块默认。允许列表存在时只在列表内生效；旧黑名单保留为对应模块的 deny，不变成全局禁用。

模块协作 v1 三项：

| 设置 | 新装默认 | 规则 |
| --- | --- | --- |
| 截图复制后加入剪贴板历史 | 关闭 | 仅影响 Metis 自己的截图输出，保留系统复制成功结果 |
| 验证码复制后加入剪贴板历史 | 关闭 | 默认不记录也不预览验证码；无需读取正文日志 |
| 剪贴板内容送入 AI | 不自动执行 | 用户在面板明确选择动作时才发送，不提供后台自动上传 |

窗口互斥、截图隐藏浮层、同一次复制去重属于内部正确性，不应向用户堆放实现开关。

## 7. 搜索、路径与通用编辑规范

- 全局搜索由静态/生成的 SettingDescriptor 目录驱动，覆盖所有层级，不只是首页可见 specifier。
- 索引字段：settingID、标题、中英别名、旧品牌名、关键词、父级路径、目标 route、可用原因。动作名称索引单独读取当前配置；绝不索引剪贴板正文、验证码、API key。
- 结果格式：“悬浮预览 → 剪贴板 / 外观”，点入页面后滚动并短暂高亮对应项。搜索“Kayoko”“截图按钮”“底部工具栏”都能命中。
- 唯一内部路由如 `settings/clipboard/floating-preview#duration`；外部如 `metis://settings/clipboard/floating-preview` 是请求协议，实际能否拦截需实现与验证，不能只写 Info.plist 就声称可用。
- 关闭模块的搜索结果仍可进入；缺失能力给出原因并阻止测试。
- 开关、滑条：短暂合并写入；完成写入后再通知；页面显示已保存/失败/待重新打开 App。
- 复杂表单：保存/取消；离开有未保存修改提示。列表稳定 ID，与 cell index 解耦，过滤/分组后不再用旧 index 删除。
- 自定义排序：拖动把手；隐藏项保留数据；支持批量选择与撤销当次删除。禁止用重排重建 UUID。
- 高级参数有单位、范围、恢复默认；校验错误定位字段，不让无效值写入运行快照。
- 模块页内预览复用纯布局模型，不加载真正运行时浮窗或调用启动目标 App 的私有接口。
- Light/Dark、动态字号、VoiceOver、横屏、小屏与 iPad 宽度都要验证；信息不单靠颜色区分。

## 8. 设置状态与生效提示

`保存中 → 已保存 → 运行端已确认` 是不同状态。保存失败保留编辑值并给重试，不回显错误的成功。

| 变更类型 | 用户提示 | 实现要求 |
| --- | --- | --- |
| 布局/颜色/动作引用 | 已保存，当前会话按能力刷新 | 后续 config generation 生效，活动任务仍持自己的快照 |
| 构造期才安装的 hook | 需要重新打开受影响 App | 必须区分“配置已开”和“hook 尚未安装” |
| SpringBoard 装载目标或 hook 集合变化 | 需要重新载入桌面 | 收集为一个待处理条目，由用户主动点重载 |
| 清空历史/恢复备份 | 显示操作进度与结果 | 不用“重载桌面”替代事务/锁处理 |

全局关闭的按钮文案为“停用 Metis 功能”，诊断提示“注入库将在进程重启后重新加载”；不要把业务停用描述为卸载。

## 9. 首次使用与迁移

新装进入首页即可浏览全部设置。Metis 默认总开、三个模块默认关；用户逐个启用需要的模块。引导不强制一次完成，不自动启用剪贴板记录。

首次发现旧数据展示一张可关闭的“导入旧配置”行。进入后：检测来源 → 选择模块 → 预览变更/冲突 → 生成备份 → 导入 → 显示结果。导入旧 enabled 值不等于立即允许执行：迁移事务全部成功且用户选择启用后才解锁运行。

新装仅在剪贴板模块启用时询问要记录文本/图片哪几类；导入用户保留其既有选项，不用新默认覆盖旧值。完整事务见 05。

## 10. 可用性验收

1. 首页进入任一模块只需一次点击；常用配置通常在三次点击内到达（不含系统“设置”入口）。
2. 从首页搜索“预览持续时间”能直达剪贴板悬浮预览相应行；关闭模块不阻断查找。
3. 用户修改一个动作名称后，所有引用位置同步显示新名称，无需逐个修改。
4. 用户为同一系统手势分配第二动作时，保存前看到可理解的冲突说明。
5. 总关闭后旧 URL、工具栏、剪贴板观察者均无法继续触发业务；配置仍可编辑。
6. 恢复模块设置不会删除历史；清空历史不会删除动作和收藏；所有破坏性行为有范围说明。
7. 暴露的每个设置有唯一 settingID、测试、默认和生效策略。缺失任何一项视为未完成。
