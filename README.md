# Metis

Metis 是一款 iOS 越狱插件（RootHide Bootstrap，支持 iOS 16 / iOS 17）：**一个安装包、一个系统设置入口、三个可独立开关的模块**——截图与标注、键盘与操作、剪贴板。

系统设置 → Metis 是唯一入口，总开关一键暂停全部功能，配置保留不丢；各模块也可单独关闭。

## 截图与标注

### 多种截图方式

- 全屏截图、区域截图、全屏标记、图片编辑（优先取剪贴板图片，也可从相册导入）。
- 冻结截图：定格当前画面，再慢慢框选。
- 即时区域：拖出选框立即成图，界面只留「取消 / 全屏」两键。
- 滚动长截图提供三种算法：
  - Metis 自适应滚动（默认）：自动逐屏采集拼接；
  - SHELLX 自动拼接；
  - 快速滚动截图：自己滑动页面，右上角实时预览，滚到底自动保存，支持暂停 / 继续 / 随时复制。

### 可定制的选框与悬浮图

- 区域选框工具栏按钮可排序、显隐、改名、换图标；按钮样式支持图标 / 文字 / 图标＋文字（上图下字），支持多排布局与统一图标大小。
- 记住上次选区；选框贴近屏幕边缘自动吸附，吸附距离可调。
- 截图完成后生成悬浮图：常驻屏幕、可拖动、双击关闭、长按展开「保存 / 复制 / 编辑 / 取消」动作条；新截图时自动隐藏，避免被截进图里。
- 工具栏可添加任意数量自定义 URL 按钮，一键打开指定链接。

### 专业标注编辑器

- 15 种标记工具：画笔、平移、方框、椭圆、箭头、直线、放大镜、马赛克、文字、实心方、实心圆、聚光灯、荧光笔、贴纸、序号图章。
- 撤销 / 重做（多级）、裁剪、旋转、删除、置顶、适屏、面板停靠与收起、完成并复制。
- 自定义颜色彩虹环＋「最细 / 最粗」线宽滑杆；贴纸可旋转，文字与笔画可捏合缩放，放大镜倍率可调。
- 全屏标记模式使用冻结整屏底图与悬浮多排面板；普通编辑为圆角卡片布局。

### 套壳截图

- 独立套壳截图入口，普通编辑器与全屏标记也可一键打开套壳面板；不依赖 ShellX 安装。
- 内置灵动岛、刘海、经典 Home 三种机壳，可调机身颜色、背景、留白与阴影；横屏自动转壳，内容等比完整显示。
- 支持随机素材、导入 PNG＋四角配置的自定义透视机壳；样式可记忆，原图和标注保持可继续编辑。
- 保存、复制、分享统一使用套壳结果；透明背景保留 PNG。系统动作中的「套壳截图」可绑定键盘按钮或全局手势。

### 灵活输出

- 五种输出动作：保存到相册 / 复制到剪贴板 / 系统分享 / 保存并复制 / 保存并删除源图。
- 超长图超出复制上限时自动降级为仅保存并提示。
- 完成时可选震动反馈；悬浮图阴影可关。

### 外部调用

- iOS 捷径「打开 URL」即可触发：`prefs://root=metis_full`（全屏）、`metis_frame`（套壳）、`metis_area`（区域）、`metis_markup`（全屏标记）、`metis_long`（滚动）、`metis_edit`（图片编辑）。
- 兼容 Snapper3、SHELLX 的通知入口；截图按钮工具栏可外调 SHELLX 全部功能（区域 / 即时 / 冻结 / 套壳 / 长图 / 翻译 / 扫码等，未安装 SHELLX 时按钮自动隐藏）。

## 键盘与操作

### 键盘工具栏

- 顶 / 底两条工具栏独立配置：全选、复制、剪切、粘贴、撤销、重做；删除 / 向后删除 / 删词 / 清空；选择整行 / 整段 / 整句；光标按词、行、段、句、文档精移；查词、命令行、交错大小写（随机 / 交替 / 元音 / 辅音四种风格）。
- 联动动作按安装检测自动出现：ShellX 截图、Metis 截图、AI 问答、剪切板、小把手等。
- 按钮全面定制：内置图标库（SF Symbols / 应用图标按分类挑选）、边框与粗细、按钮大小 / 高度 / 圆角 / 间距、顶部多行布局（最多两行 16 个）、底部最多 8 个，附工具栏预览与测试输入框。
- 每个按钮六槽手势：单击、长按、上滑、下滑、左滑、右滑，各绑一个动作。
- 快捷方式可配置命令行命令；也可设置点击快捷方式循环切换已启用的输入法。

### 底栏编排与上下文动作组

- 底栏左右段混排三种条目：固定动作、上下文动作组、速启应用；支持交换左右段、单段占满、等宽格、边框显示，实时预览。
- 按输入场景动态替换底栏预留区（固定按钮位置不变）：选中文字（打开链接 / 搜索 / 问 AI）、复制后新鲜期内一键粘贴、粘贴后短暂显示撤销粘贴、验证码输入框出「粘贴验证码」、网址框出「打开剪贴板链接」等。
- 内容类型智能分类：文本、网址、数字、地址、电话、日期、中英混合等，可添加自定义 JS 规则扩展（沙箱限流，防止卡顿）。
- 去抖延迟、剪贴板新鲜期、粘贴后显示时长、操作后锁定、上下区占位格数均可调。

### 键盘面板与全局手势

- 可创建多个「键盘面板」和「手势面板」；面板为分页宫格布局，每行图标数与内容大小可调，支持长按拖动排序、宫格预览。
- 面板可带系统开关排（勿扰 / Wi-Fi / 静音 / 蓝牙 / 方向锁）与亮度 / 音量滑杆。
- 全局手势（任意界面可用，均自由绑定动作或面板）：
  - Dock 手势：上滑 / 左滑 / 右滑；
  - 状态栏手势：左中右三个区域 × 单击 / 双击 / 长按 / 左滑 / 右滑，横屏可单独启用；
  - 屏幕边缘手势：单指 / 双指从左右两侧滑入，触发区域与距离可调，带调试可视化；
  - 边缘划弧手势：从左下 / 右下角划出唤出面板，扇形半径可调。

### 自定义动作（七种类型）

- **链接协议**：URL Scheme 打开，支持悬浮小窗打开、`@@@` 传入输入框内容、剪切替换。
- **常用文本**：单条直接插入，多条弹出悬浮列表点选，支持排序编辑。
- **打开应用**：默认以小窗悬浮打开（可拖动标题栏、一键收起），也可全屏打开。
- **快捷方式**：应用长按菜单快捷项，静态 / 动态来源可选。
- **系统动作**：媒体控制；控制中心（录屏、手电筒、Wi-Fi、蓝牙、飞行模式、亮度、音量、深色模式、勿扰等）；设备操作（注销、关机、重启、安全模式、返回桌面、打开后台、快速面板等，破坏性动作需确认）；截图动作（全屏 / 区域 / 全屏标记 / 滚动 / 图片编辑）。
- **AI 动作**：选人设与模型直接提问，输入框为空时只打开面板。
- **JS 脚本**：`main(str)` 入口，输入可选选区 / 全文 / 剪贴板，输出可选替换 / 插入 / 复制；支持 `$http`、`$url`、`$app` 与菜单返回；内置测试运行，支持 AI 生成脚本。
- 动作库支持分组、批量管理、类型筛选、搜索、排序；动作可加入面板或绑定到按钮、手势。

### AI

- 内置通义千问、DeepSeek、OpenAI、硅基流动、豆包、智谱、Gemini 七个引擎，可添加任意 OpenAI 兼容自定义引擎，支持一键抓取模型列表、API 余额查询。
- 多人设切换（首位默认）、流式输出、Markdown 渲染（标题 / 列表 / 引用 / 代码块 / 链接等）、发送相册 / 相机 / 文件附件。
- AI 生成脚本：多轮对话修改、直接调试、版本回退、换一版。

### 快速面板与悬浮应用

- 快速面板：任意界面唤出速启；常用应用按启动次数自动推荐排序；九键数字搜索全部可启动应用，支持搜索别名与邻键容错；可自由摆放、双击复位、超过六个自动翻页。
- 悬浮应用：应用以小窗悬浮打开，双指缩放，「滚动放大，离开缩小」，停靠位置与默认大小可调；点击小窗外直接操作底层应用。
- 后台 App 停靠栏：底部工具栏收纳最近缩下的小窗（一行最多 6 个，最近的最先），一键唤回。

### 贴心小功能

- 粘贴悬浮窗：剪贴板有新内容时在键盘上方弹出「粘贴」，并自动放行系统「允许粘贴」弹窗；可按应用选择性生效。
- 短信验证码自动复制：中英文关键词＋4–8 位数字识别，自动排除订单 / 快递 / 优惠券等干扰场景。
- 触感反馈开关。

## 剪贴板

### 面板与历史

- 六种激活方式：预测栏、听写键、输入法菜单、编辑菜单、单指上划、⌘⇧V 外接键盘。
- 文本 / 图片 / 富文本「历史记录 + 收藏夹」双列表；文本与图像可分开保存，条数上限可调，自动置顶策略可选（仅历史 / 总是）。
- 画廊双列宫格视图（历史与收藏各自记忆）；预览行数、条目详情（捕获时间、字数 / 尺寸、文件大小）可配。
- 搜索：关键词＋筛选令牌（类别 / 应用 / 标签，可多段组合）；自定义彩色标签；条目可加备注。

### 条目操作

- 收藏⇄历史互移、保存到照片、打开链接、复制、删除，以及与键盘共享的系统动作目录；装了 Snapper 可固定到其浮窗。
- 滑动选词：长按文本条目进入选词模式，轻点选中、滑动扩展 / 缩小。
- 文本工具、翻译、Spotlight 聚焦。
- 文本动作、图片动作、图片双击动作可引用全局动作库，`$$@` / `@@@` 占位符把条目内容传入后打开。

### 自动粘贴与悬浮预览

- 点选条目直接粘贴回原输入框（自动恢复焦点），三种粘贴模式可选；可自动放行系统「允许粘贴」弹窗。
- 悬浮预览：悬浮球常驻屏幕边缘，流光倒计时，大小 / 颜色 / 时长 / 双击动作可调。

### 隐私与控制

- 隐私模式；应用黑名单（不记录指定应用的剪贴板）；忽略通用剪贴板。
- 面板视图优先级自调（附状态栏 / 锁屏 / 控制中心等参考值）；触摸外部收起。
- 清空按钮策略、自动粘贴模式、手势识别器方案可选。
- 危险区均有二次确认；旧数据一键导入；数据目录检查与缩略图缓存维护。

## 设置与通用

- 系统设置 → Metis 唯一入口；总开关＋三个模块开关独立控制，首页按「全局 / 键盘 / 剪切板 / 截图」分类直达。
- 首页搜索设置项，直达目标页并高亮。
- 配置备份 / 恢复：一键备份全部功能配置（键盘、剪贴板、截图、速启与共享资源），本机保留最近 10 份自动淘汰，可导出为文件分享；恢复前自动创建安全网备份，恢复后立即生效无需重启。
- 引用管理：动作与面板的反向索引，查看每项资源被哪些入口引用，未被引用的可安全删除。
- 共享资源：自定义动作与面板在键盘、剪贴板、手势等入口之间复用同一份，改一处全局生效。
- 更新说明：每个版本的用户可见变化在设置页一目了然。
