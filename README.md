# Metis

Metis 计划将 PixPin（截图与图片编辑）、TypeX（键盘效率与动作）和 KayokoX（剪贴板管理）整合为一个 iOS RootHide 插件集合。

当前仓库阶段：**开发规格与 agent 执行手册已归档，尚未实现插件代码。** 文档中的新类、目录、配置格式和命令均为待开发规格；不能据此宣称已编译或已支持真机。

从 [开发手册](DEVELOPMENT.md) 开始阅读。重点设置设计见 [设置界面规格](docs/development/02-settings-ux.md)，集成方案见 [运行架构与接口](docs/development/03-architecture.md)。
